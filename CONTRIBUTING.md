# Contributing to Unio

Thanks for your interest in contributing to Unio! 🎉
This project is open source and any kind of contribution is welcome: bug reports, new features, documentation improvements, or fixes.

## 🛠 How to Start

1.  **Fork the repository**: Create a copy of the project on your GitHub account.
2.  **Clone the project**: Download your fork locally.
3.  **Open in Xcode**: Open `Unio.xcodeproj` with the latest stable version of Xcode.

## 🐛 Reporting Bugs

Use the GitHub **Issues** section.
When opening an issue, please try to include:
*   Your device model (e.g., iPhone 18 Pro).
*   The iOS version (e.g., iOS 18.2).
*   Precise steps to reproduce the issue.
*   Screenshots or videos if applicable.

## 💻 Development & Pull Requests

1.  **Create a Branch**: Never work directly on `main`. Create a branch for your feature or fix:
    ```bash
    git checkout -b feature/new-feature
    # or
    git checkout -b fix/bug-fix
    ```
2.  **Code Style**:
    *   Follow standard Swift conventions and strict concurrency.
    *   Keep code clean and self-documenting.
    *   If modifying UI, always verify behavior in both Light and Dark modes.
3.  **Test**: Verify that the app and extensions compile cleanly (`Cmd + B`) before submitting.
4.  **Submit Pull Request**:
    *   Clearly describe what you have changed.
    *   Link the PR to an existing Issue if present (e.g., "Fixes #12").
